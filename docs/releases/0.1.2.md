### Install or update

Download **keydoku.apk** below. Requires **Android 6.0 or newer** and a **physical keypad or keyboard**; there is no on-screen number pad.

Already using 0.1.1? Install this APK over it. The signing key is unchanged, so your local progress and settings stay intact. Users of the older 0.1.0 preview must uninstall that version first, which clears local progress.

For automatic update checks, add `https://github.com/d4mysus/Keydoku` to Obtainium. **SHA256SUMS** contains the APK's SHA-256 checksum.

No ads, accounts, analytics, or network permission. All features remain free; donations are optional. Licensed under GPL-3.0-only.
