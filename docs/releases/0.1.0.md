The initial Keydoku release brings offline Sudoku to Android keypad phones, with a compact layout designed for devices such as the Dumber Mini.

### Features

- Easy, Medium, Hard, and Expert puzzles with a unique solution
- Physical keypad navigation and digit entry, with optional touch cell selection
- Notes, hints, undo/redo, a timer, and local statistics
- Optional sound, haptic feedback, and developer donations
- No ads, accounts, analytics, or network permission

### Installation

Requires **Android 6.0 or newer** and a **physical keypad or keyboard**. The APK attached to this release is **com.keydoku.apk**.

This is the older preview release. Version 0.1.1 and later use a new signing key; moving from this APK to that key requires a one-time uninstall, which removes local progress.

For current releases and updates, visit [GitHub Releases](https://github.com/d4mysus/Keydoku/releases). [Report bugs here](https://github.com/d4mysus/Keydoku/issues).
